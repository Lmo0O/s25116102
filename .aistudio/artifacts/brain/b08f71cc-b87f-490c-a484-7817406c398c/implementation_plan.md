# 湖畔成就任務抽屜與獎勵系統實作計畫（已完成）

為《像素悠閒釣魚日》增加湖畔右側可隨時展開與收合的「成就任務抽屜」，提供 10 項豐富的階段性成就、即時達成像素提示彈窗、與可手動領取的豐厚金幣獎勵系統。全數功能已實作並通過編譯與代碼驗證。

## User Review & Critical Decisions

> [!IMPORTANT]
> 依據用戶在 Phase 1 的選擇確認：
> 1. **介面形式**：採用「湖畔側邊可隨時展開的成就任務抽屜」，保持湖泊全景的開闊平靜，隨時可點擊右側懸掛木質標籤或按快捷鍵展開檢視。
> 2. **反饋與獎勵**：達成時即時跳出頂部像素風格的成就解鎖提示橫幅，並在抽屜內提供「🪙 領取」按鈕發放額外金幣獎勵，附帶金色紙花與硬幣音效。

- **已確認決策 1**：成就抽屜收合於右側邊緣，帶有精緻的「🏆 成就」木牌拉手標籤與未領取紅點徽章。
- **已確認決策 2**：10 項階段式成就涵蓋初入湖畔、特定魚種捕捉（河豚、紫色魚、黃金魚）、累積隻數、財富累積與全圖鑑收集。

---

## 1. Overview & Core Concept

- **功能定義**：玩家在享受寧靜釣魚的過程中，能透過長線目標獲得持續的反饋與成就感。抽屜平常隱藏於螢幕右側邊緣，不遮擋主要垂釣視角；當達成目標時彈出通知並可在抽屜內點選領取金幣。
- **目標用戶**：喜愛收集、休閒養成、達成 100% 圓滿圖鑑的玩家。
- **核心價值**：強化遊戲的重玩價值與目標感，金幣獎勵更可讓玩家加速累積財富。

---

## 2. User Experience & Visual Design

### Key User Flows

1. **瀏覽與進度檢視**：
   - 湖畔右側常駐「🏆 成就」木紋書籤拉手標籤（帶有懸掛金牌像素質感）。
   - 點擊標籤或按下鍵盤 **[A]** 鍵，右側成就抽屜以順暢的 CSS 抽屜滑入動效（Slide-in）展開。
   - 頂部顯示總體成就完成進度條（如：`已達成 4 / 10 項 (40%)`）。
   - 每個成就項目顯示專屬像素圖示、成就名稱、達成條件、即時數字進度條（例如：`3 / 5 隻`）、金幣獎勵數量，以及「進行中」、「可領取（閃爍高亮）」或「已領取」按鈕狀態。

2. **達成瞬間驚喜反饋**：
   - 當釣獲特定魚或達到累積門檻時，即時觸發 8-bit 成就號角音效與金色粒子特效。
   - 頂部滑出像素風「🏆 成就解鎖！【xxx】+🪙 XX」提示通知，隨後自動優雅收回。
   - 右側抽屜標籤亮起黃色驚嘆號提點玩家前往領取。

3. **獎勵領取反饋**：
   - 打開抽屜點擊「🪙 領取」，播放金幣叮噹音效，跳出飄浮數字動效，金幣即刻注入頂部金幣計數器。

### Visual Identity & Theme

- **整體風格**：承襲 16-bit 復古像素風，使用溫暖原木棕 `#3c2410`、復古紙張羊皮底色 `#fdfbf6`、湖水藍與金色飾邊。
- **抽屜尺寸**：桌面端寬度 360px，手機端自適應 85vw，背景半透明暗色遮罩（點擊遮罩即收合）。
- **字型配置**：維持 `DotGothic16` 像素字型與 `Press Start 2P` 數字。

## 3. Key Product Decisions & Trade-Offs

- **決策 1：側邊抽屜 vs 全螢幕彈窗**
  - *選擇*：側邊抽屜（Side Drawer）。
  - *原因*：使用者明確指定；抽屜開啟時仍能看見左側的釣魚角色與湖面，保留空間連續性。
- **決策 2：手動領取獎勵 vs 自動發放**
  - *選擇*：手動點擊「領取」發放金幣。
  - *原因*：提供玩家直接點擊領取的回饋爽感，同時可在未領取前保留未讀紅點提點。
- **決策 3：資料持久化**
  - *選擇*：整合至現有 `localStorage` 的 `pixel_fishing_game_data_v1` 架構中，向下相容已有的金幣與圖鑑記錄，無痛載入。
